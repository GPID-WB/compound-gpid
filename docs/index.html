Compound GPID structures AI-assisted development for data scientists, economists, and technical teams working under institutional constraints. It connects planning, implementation, review, and reusable project knowledge while keeping human judgment visible, testable, and accountable.

What the plugin provides

A structure for responsible AI-assisted work.

The canonical .github/ source is owned through a three-layer registry: kernel, reusable capability packs, and independent technical /cg-* and research /cr-* suites. Release-validated native trees support GitHub Copilot, Claude Code, Codex, OpenCode, and Kilo. Read the Modular Guide to choose a suite.
