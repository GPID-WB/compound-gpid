01 / STANDARDcg

The foundation
for everyday work.

Turn an idea into tested code. Plan a change, fix a bug, review a pipeline, and preserve the reasoning that made it work.

  • Explicit plans and acceptance criteria
  • Implementation, tests, and risk-based review
  • Project memory and reusable lessons
