# Skills for building applications

**The idea.** Carry skills for web front ends, API design, browser testing, accessibility audits, observability and launch checklists, as the source repositories do.

**Why not.** The plugin serves analysts. Their outputs are estimates, datasets, reports, packages and simple dashboards. Skills for application work would sit in every analyst's context and serve almost none of them.

**What would reopen it.** Analysts asking for it from real work. It would then be a pack, not part of core.
