# Activate Workflow

1. Resolve one known current capability.
2. Plan a source-span edit of only the top-level inline `capabilities` value.
3. Re-resolve the exact manifest and every selected platform projection without live writes.
4. Store a digest-bound plan.
5. Apply config, manifest, generated output, host projections, and ownership through one held-lock journal.

Activation is explicit. Eligibility selectors can reject selection but cannot activate a project skill.
