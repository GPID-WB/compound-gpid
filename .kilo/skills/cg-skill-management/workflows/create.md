# Create Permanent Skill

Use `create` only from a validated canonical maintainer feature-branch checkout.
Supply permanent scope, explicit owner and capability metadata, complete suite and
platform eligibility, activation cost, triggers, selectors, approver audit label,
and an immutable review reference. The plan scaffolds only requested focused
resources and applies the canonical non-data policy before it records actions.

Creation is inactive by construction. An existing capability is accepted only
when it is `explicit-only` and its owner is absent from the fresh active manifest.
Apply publishes source, provenance, registry, manifest, generated targets, and
projections through the common expected-byte transaction.
