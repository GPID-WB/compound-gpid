## roxygen2 Documentation

```r
#' Compute weighted statistics for survey data
#'
#' @param dt A [data.table] with survey data.
#' @param var Character. Column name for the variable.
#' @param weight Character. Column name for weights.
#' @param by Character vector. Grouping columns.
#'
#' @return A [data.table] with weighted means and SDs.
#' @export
#' @examples
#' dt <- data.table(id = 1:100, y = rnorm(100), w = runif(100), g = rep(1:5, 20))
#' compute_stats(dt, "y", "w", "g")
compute_stats <- function(dt, var, weight, by) {
  g <- GRP(dt, by)
  data.table(
    group    = GRPnames(g),
    mean     = fmean(dt[[var]], g = g, w = dt[[weight]]),
    sd       = fsd(dt[[var]], g = g, w = dt[[weight]]),
    n        = fnobs(dt[[var]], g = g)
  )
}
```

## Development Workflow

```r
devtools::document()   # Generate man/ and NAMESPACE
devtools::check()      # Full R CMD check
devtools::test()       # Run all tests
devtools::install()    # Install locally
```

## pak vs renv

- **pak** — fast development installs: `pak::pkg_install("collapse")`
- **renv** — project-level lockfiles: `renv::init()`, `renv::snapshot()`, `renv::restore()`
- **Workflow**: `pak::pkg_install()` to add, `renv::snapshot()` to lock

Commit `renv.lock` and `renv/activate.R`. Do NOT commit `renv/library/`.
