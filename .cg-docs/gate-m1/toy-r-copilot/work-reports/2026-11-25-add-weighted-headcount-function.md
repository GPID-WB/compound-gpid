# Add weighted headcount function

## Asked

Add a function `headcount(dt, line = 3)` that returns the weighted share of
households with welfare below `line`, with a testthat check. The expected toy
survey result is `0.153846`.

## Risk

Every line was no. The change adds one pure package function and tests; it does
not move an existing published estimate, read governed data, touch credentials,
delete or overwrite data, add dependencies, or require a large or ambiguous
change.
