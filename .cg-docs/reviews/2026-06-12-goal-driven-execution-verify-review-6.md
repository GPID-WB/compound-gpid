## Findings

### P1 - Critical

**[P1.1]** [cg-code-quality] `scripts/link.ps1:101` - Legacy `.github` junction could cause writes into the shared install.

**Issue**: `Ensure-CgRootDirectory` excluded `.github` from legacy whole-root junction migration. On Windows, an old Compound-owned `.github` junction could be treated as usable, letting generated `.github/copilot-instructions.md` write through the junction into the global Compound GPID install with project-specific config.

**Fix applied**: Removed the `.github` exception so Compound-owned whole-root `.github` junctions migrate to a real project root directory before child install units are linked. Added a regression guard in `tests/link.Tests.ps1`.

### P2 - Important

**[P2.1]** [cg-code-quality / cg-testing] `scripts/link.sh:176`, `tests/link.Tests.ps1:44` - Bash linker and tests did not cover legacy `.github` symlink migration.

**Issue**: `link.sh` also special-cased `.github`, so macOS/Linux legacy `.github` symlinks could not converge to the new per-unit layout. Tests only checked junction identity/removal in isolation.

**Fix applied**: Removed the `.github` exception in `link.sh`; added bash-side and PowerShell-side regression guards.

**[P2.2]** [cg-code-quality] `scripts/link.ps1:321`, `scripts/link.sh:379` - Partial relinks could drop existing managed `.gitignore` entries.

**Issue**: `Update-CgGitignoreBlock` received only units installed in the current `--platforms` run, so relinking a subset such as `--platforms opencode` could remove still-present managed entries for other platforms from the CG `.gitignore` block.

**Fix applied**: Added existing-managed-entry collection before rewriting `.gitignore` in both PowerShell and bash linkers; added regression guards.

**[P2.3]** [cg-testing] `scripts/install.sh:92` - Uninstall path lacked coverage for newly generated wrappers.

**Issue**: `install.sh --uninstall` removed only `cg-link`, `cg-unlink`, and `cg-update`, leaving generated Python-backed wrappers such as `cg-index`, `cg-brain-init`, and `cg-token-audit`.

**Fix applied**: Extended uninstall cleanup to all wrappers generated by `install.sh`; added macOS uninstall smoke coverage in `tests/bash-scripts.Tests.ps1`.

**[P2.4]** [cg-code-quality] `tests/update.Tests.ps1:221` - Manifest refresh tests were vacuous.

**Issue**: The prior checksum tests compared local variables instead of executing production refresh logic.

**Fix applied**: Extracted `Update-CgManagedPlatformFiles` into `scripts/helpers.ps1`, wired `scripts/update.ps1` to call it, and added tests for checksum-match refresh, user-modified skip, and missing-target manifest cleanup.

**[P2.5]** [cg-testing] `scripts/tests/test_update_generates_targets.py:98` - Bash wrapper Python fallback tests were positive-only.

**Issue**: Tests only asserted that `resolve_python` and candidate names existed; a wrapper could still directly execute `python3` and pass.

**Fix applied**: Added negative assertions banning direct `python3` execution patterns in all changed Python-backed bash wrappers.
