# Version 1 records left open

These 31 records (19 plans, 11 work reports and one review) were written by Compound GPID version 1 and never
closed. They were moved here unchanged on 2026-11-27, at the maintainer's decision, so that `cg.py status` no longer
counts them as open work and a `/cg` session on this repository does not take one for the current work. Notes of
version 1 elsewhere in `.cg-docs/` still link to their old places. To bring one back, move it to its old folder with
`git mv`.
