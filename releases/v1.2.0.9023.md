# v1.2.0.9023 - Kilo Independence

## What Changed

Compound GPID install, update, link, and unlink do not run Kilo. They do not
depend on a Kilo version or host behavior. Local validation of generated
Compound GPID files and ownership checks remain.

When Kilo and Claude or Codex skills coexist, a non-blocking note recommends
`cg-kilo` for contained launches. The optional launcher keeps
`KILO_DISABLE_EXTERNAL_SKILLS` containment. Old or unreadable Kilo versions
produce warnings, not a version gate.

## Upgrade From 9022

1. Open a terminal in a **NEW EMPTY FOLDER**. Do not use your home folder or a
   Kilo-linked project. The installed 9022 updater still has the old host check.
2. Run `cg-update v1.2.0.9023`. Stop if it fails. Do not use `latest` or `--fix`
   to bypass an error.
3. After success, run the NEW `cg-link` once in each project. Keep the adapter
   selection used by that project and check each result.

## Mac Installs On 9006-9016

Use the same re-clone procedure as 9022, with the 9023 tag:

1. Close tools and terminals that use the installation. Record the original
   path, commit, version pin, and local changes. Back up projects, including
   private configuration and ownership records.
2. Move the old installation clone aside. Keep it outside adapter discovery
   folders; do not delete it or discard local changes.
3. Clone `https://github.com/GPID-WB/compound-gpid.git` at the SAME original
   installation path. In the new clone, run
   `git checkout --detach v1.2.0.9023`, then
   `printf '%s\n' v1.2.0.9023 > .cg-version`.
4. Run `bash "<original-install-path>/scripts/install.sh"`. Stop on failure.
5. Open a new terminal. Check that `command -v cg-link` points to the new clone.
   Run the NEW `cg-link` once per project and check each result.

If linking blocks or preserves old files, keep the files, ownership records,
journals, and private configuration. Use reviewed manual repair. Do not delete
an adapter folder or use `cg-unlink` as a cleanup shortcut.

For rollback, close affected tools, move the new clone aside, and restore the
old clone at its original path. Run its installer and open a new terminal.
Clone rollback does not undo project changes; restore only reviewed backups.
The known 9022 Windows PowerShell 5.1 long-path copy/unlink limits remain.

## Publication

Every four-part `vX.Y.Z.N` tag uses Reserve-only publication: a non-draft
pre-release with `make_latest=false`. No Finalize, docs deployment, or
attestation applies. Three-part stable tags keep the full path.

Publication is conditional on successful local gates and all applicable push
and FULL CI rows. The payload date is the preparation date, not publication
proof. No real local installation or real Kilo launch is part of this work.
