# Validate Workflow

1. Validate every registered operation descriptor for complete declared assets.
2. Resolve manifest health and the canonical registry snapshot.
3. Inventory one requested canonical bundle or all canonical bundles.
4. Validate frontmatter, source confinement, portable paths, local Markdown
   links, ownership, and capability-record consistency through shared services.
5. Sort common findings by severity, path, and code. Return exact remediation
   and do not write or repair files.
