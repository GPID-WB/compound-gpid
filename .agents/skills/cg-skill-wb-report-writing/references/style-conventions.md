# Style Conventions

## Authority

Primary cross-cutting authority:
- WBG Publications Editorial Style Guide (2020)
- Source URL: https://openknowledge.worldbank.org/
- Retrieved: 2026-07-23
- Version note: apply current approved guidance; update retrieval note when
  source guidance changes.

## Distillation Rule

Distill style conventions into original language. Do not copy exemplar prose
or source text verbatim beyond short terms required for accurate usage.

## Core Conventions

- Use clear, formal institutional prose aimed at policy and technical readers.
- Prefer concrete, source-grounded statements over rhetorical language.
- Keep heading structure consistent and descriptive.
- Use table and figure language that preserves uncertainty where required.
- Use date, number, and currency formatting consistently within a document.
- Keep citations traceable and explicitly marked when unverified.

## Scope Boundaries

- English output only.
- Markdown and basic .qmd structure/prose only.
- Defer full typesetting, code execution, and data-binding workflows.
