# Check Freshness

Verify whether a rendered HTML view is current, stale, or missing relative to
its canonical Markdown source.

## Usage

```bash
cg-render-artifact --check .cg-docs/plans/example.md
cg-publish-markdown --check README.md
```

## Output

- `current <path>` — the view matches the source byte-for-byte.
- `stale <path>` — the view exists but differs from the expected output.
- `missing <path>` — no view exists at the expected path.

## Exit Codes

- `0` — current
- `1` — stale or missing
- `2` — invalid input, source, resource, path, or theme

## Theme Awareness

When `--theme` is passed, the check compares against the expected output for
that theme. When omitted, the check uses the document-type default or the
theme recorded in the existing view's provenance.

## Recovery

A stale or missing view can be regenerated by running the render command
without `--check`:

```bash
cg-render-artifact .cg-docs/plans/example.md
cg-publish-markdown README.md
```
